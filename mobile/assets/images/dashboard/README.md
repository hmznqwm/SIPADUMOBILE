# Dashboard Card Assets

Folder ini digunakan khusus untuk meletakkan gambar/ilustrasi/foto header yang tampil di atas teks "Panel Kontrol" atau header card dashboard.

## Rekomendasi File:
- **Nama File**: `dashboard_card_header.png` (atau format JPG / WebP)
- **Format**: PNG transparan atau JPG bersih
- **Ukuran**: Sekitar 400x150 px atau rasio lebar horizontal
