# Logo Assets

Letakkan file logo/icon di folder ini.

## Cara Pakai:
1. Simpan file gambar logo ke folder ini (contoh: `logo.png`)
2. Aplikasi akan otomatis menampilkannya di halaman login

## Format yang Didukung:
- PNG (disarankan, mendukung transparansi)
- JPG
- SVG (jika menggunakan package flutter_svg)

## Ukuran yang Disarankan:
- Minimal 256x256 px
- Latar belakang transparan (PNG)
